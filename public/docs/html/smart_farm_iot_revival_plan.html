01

§เป้าหมาย & หลักคิด

เฟสนี้ตอบคำถามเดียว: "ของเดิมที่มีอยู่ ยังใช้งานได้จริงแค่ไหน?" โดยไม่เอาเรื่องย้าย Firebase หรือแก้ security ทั้งหมดมาปนกัน — แยกทีละชั้นแบบนี้:

ลำดับทำอะไรไม่ทำอะไร
1จัดไฟล์เข้าโครงสร้างที่อ่านง่ายไม่แก้ logic ใด ๆ
2แก้เฉพาะบั๊กที่ทำให้ผลลัพธ์ผิด/รันไม่ได้ไม่แตะเรื่อง security/ย้าย backend
3เว้นส่วนที่พึ่งบริการตายแล้วไว้ (stub เฉย ๆ)ไม่หาทางแทนที่ตอนนี้
4ทดสอบทีละส่วนแบบแยกอิสระไม่รอให้ทุกอย่างพร้อมพร้อมกันแล้วค่อยเทสรวด
ทำไมต้องแยกแบบนี้: ถ้าพยายามแก้ทุกอย่างพร้อมกันจะไม่รู้ว่าอะไรพังเพราะบั๊กเดิม อะไรพังเพราะของใหม่ที่เพิ่งแก้ — เฟสนี้จบแล้วควรได้ระบบที่ "เหมือนเดิมทุกอย่าง ยกเว้นส่วนที่ตายไปแล้วจริง ๆ" เป็น baseline ที่เชื่อถือได้ก่อนค่อยไปพัฒนาต่อ

03

§เว้นไว้ก่อน — ของที่ตายแล้ว

มีจุดเดียวที่ต้อง "เว้น" จริง ๆ เพราะบริการปิดไปแล้ว ไม่มีทางทำให้กลับมาใช้ได้ ต้อง stub เฉย ๆ ไม่ใช่แก้บั๊ก

จุดที่ต้องเว้นอยู่ไฟล์ไหนทำยังไงตอนนี้
ตายแล้ว LINE Notifycamera.cpp, control.cppคอมเมนต์ฟังก์ชัน LINE.notify() / LINE.notifyPicture() ออกทั้งหมด แทนที่ด้วย Serial.println() หรือเขียน log ลง SPIFFS แทนชั่วคราว เพื่อให้ยังเห็นว่าระบบ "อยากจะ" แจ้งเตือนตอนไหนบ้าง โดยไม่ต้องพึ่งบริการนี้
ทำไมแค่จุดเดียว: จากรายงานสำรวจก่อนหน้า ส่วนอื่นทั้งหมด (Google Sheet, Apps Script endpoint, LINE Bot แบบแชท) ยังใช้งานได้จริงในปัจจุบัน ไม่มีอะไรตายเพิ่ม — เว้นเฉพาะจุดนี้จุดเดียวก็พอ ไม่ต้อง over-engineer เผื่อกรณีอื่นที่ยังไม่ได้เกิดขึ้นจริง
04

§แก้ก่อนถึงจะรันได้ถูกต้อง

3 บั๊กนี้ไม่เกี่ยวกับบริการภายนอกเลย เป็นความผิดพลาดในโค้ดล้วน ๆ ต้องแก้ก่อนเริ่มทดสอบ ไม่งั้นผลทดสอบจะเชื่อถือไม่ได้

ไฟล์บั๊กวิธีแก้
sensors.cppตัวแปรพินสลับกัน soil_1_3 อ่านจาก soil_1_1_pinแก้ให้ตรงชื่อตัวแปร soil_1_3_pin / soil_2_1_pin
sensors.cppsum_soil_all = soil_1_1; เขียนทับค่าเฉลี่ยลบบรรทัดนี้ทิ้ง ใช้ผลจาก cal_sum_soil_all/12 ที่คำนวณไว้แล้ว
rtc_time.cppnow_day = now.minute(); นับวันผิดหน่วยเปลี่ยนกลับเป็น now.day() ตามที่คอมเมนต์ไว้เดิม
ไม่บังคับแต่แนะนำทำไปพร้อมกัน: ย้าย WiFi password / รหัสกล้อง ไปไว้ใน secrets.h เพราะแค่จัดโครงสร้างไฟล์ใหม่ (ข้อ 02) ก็ต้องเปิดไฟล์เหล่านี้อยู่แล้ว ถือโอกาสทำเลยจะประหยัดเวลากว่ากลับมาทำทีหลัง — แต่เรื่อง auth/signature ของ Apps Script ยังไม่ต้องแตะในเฟสนี้
05

§ลำดับการทดสอบ — ทีละส่วน ไม่รอครบ

เรียงจากส่วนที่ทดสอบได้ง่ายสุด/ไม่พึ่งอะไรเลย ไปหาส่วนที่ต้องพึ่งหลายอย่าง — แต่ละข้อทดสอบผ่านได้โดยไม่ต้องรอข้ออื่น

1

Sensors (แยกอิสระ)

ทดสอบได้เลย
ไม่พึ่งอะไรนอกจากตัวบอร์ดจำลอง
  • จำลอง DHT22 + ตัวต้านทานปรับค่าแทนดินชื้นบน Wokwi
  • เช็คว่าค่าที่อ่านได้ตรงโซนถูกต้องหลังแก้บั๊ก pin สลับกัน
  • เช็คว่า sum_soil_all เป็นค่าเฉลี่ยจริง ไม่ใช่ค่าจุดเดียว
2

Control logic + Actuators

ทดสอบได้เลย
ทดสอบด้วย LED แทนรีเลย์ ไม่ต้องมีอินเทอร์เน็ตด้วยซ้ำ
  • ป้อนค่าเซนเซอร์จำลองสูง/ต่ำ เช็คว่าพัดลม/วาล์วเปิด-ปิดถูกเงื่อนไข
  • ทดสอบทั้ง 3 โหมดปลูก (เมลอน/แตงโม/สตอเบอรี่) แยกทีละโหมด
3

วันปลูก (RTC + day counter)

ทดสอบหลังแก้บั๊กข้อ 04
ยืนยันว่ารอบให้น้ำ/ปุ๋ยตามจำนวนวันคำนวณถูก
  • ตั้งเวลาจำลองใน Wokwi ให้เดินเร็ว เช็คว่า count_day เพิ่มตามวันจริง ไม่ใช่ตามนาที
4

เชื่อม Google Sheet (GET/POST)

ต้องเช็คก่อน
ยืนยันว่า ESP32 คุยกับ code.gs ได้จริง
  • ตรวจว่า Apps Script มี doGet(e) จริงหรือไม่ (ที่เคยตั้งข้อสังเกตไว้) ถ้าไม่มีต้องเพิ่มก่อนถึงจะทดสอบต่อได้
  • ยิง status=send ทดสอบว่าเขียนแถวใหม่ใน Google Sheet ได้
  • ยิง status=get ทดสอบว่าดึงค่า control กลับมาได้ครบ
5

LINE Bot แบบแชท

น่าจะทำงานได้อยู่แล้ว
ยืนยันซ้ำว่ายังทำงานเหมือนตอนสำรวจครั้งก่อน
  • พิมพ์ check_status, on_off_fan, mode_1 ในแชทจริง เช็คว่า Google Sheet เปลี่ยนค่าตาม
6

กล้อง (ไม่พึ่ง LINE)

ทดสอบแบบตัด LINE ออก
ทดสอบแค่การถ่าย/บันทึกภาพ ไม่ต้องส่งไปไหน
  • ทดสอบว่าดึงภาพจากกล้อง IP มาเก็บใน SPIFFS ได้ (ส่วนที่ยังไม่ตาย)
  • ส่วนส่งภาพผ่าน LINE ข้ามไปก่อนตามข้อ 03
06

§กลับมาหาอะไหล่เปลี่ยน (หลังทุกอย่างในข้อ 05 ผ่านหมด)

พอมั่นใจว่าของเดิมรันได้จริงครบทุกส่วนที่ยังไม่ตายแล้ว ค่อยกลับมาตัดสินใจเรื่องเดียวที่เหลือ: จะแทน LINE Notify ด้วยอะไร — มีตัวเลือกและรายละเอียดเชิงลึกอยู่ในเอกสารที่ทำไว้ก่อนหน้านี้แล้ว ไม่ต้องทำซ้ำในเอกสารนี้:

ทางเลือกสรุปสั้น ๆ
Apps Script pushMessage()ใช้ token เดิมที่มีอยู่แล้วใน Code.gs เพิ่มฟังก์ชันเดียว เปลี่ยนน้อยสุด
Firebase (ดูไฟล์ Firebase Migration Plan)ย้ายทั้งระบบไปใช้ real-time database คุ้มค่าถ้าตั้งใจพัฒนาต่อยาว ๆ

  • คอมเมนต์ LINE.notify() ทุกจุดออก แทนด้วย Serial.println() ชั่วคราว
