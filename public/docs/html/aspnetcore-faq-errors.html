ASP.NET Core — FAQ Error ที่เจอบ่อยที่สุด

รวม error ที่มือใหม่หัดเขียน ASP.NET Core เจอบ่อยที่สุด แต่ละอันบอกอาการ สาเหตุ และวิธีแก้ตรงจุด ถ้าเจอ error ที่ไม่มีในนี้ ลองคัดลอกข้อความ error ไปค้นหาตรงๆ ได้ มักมีคนเจอปัญหาเดียวกันมาก่อนแล้ว

ตอน Setup / รันครั้งแรก
Q'dotnet' is not recognized as a command / command not found
สาเหตุ

.NET SDK ยังไม่ได้ติดตั้ง หรือติดตั้งแล้วแต่ terminal ยังไม่รู้จัก path เพราะเปิด terminal ค้างไว้ก่อนติดตั้ง

วิธีแก้

โหลด SDK จาก dotnet.microsoft.com/download ติดตั้งให้เสร็จ แล้วปิด terminal เดิมและเปิดใหม่ (สำคัญมาก หลายคนพลาดตรงนี้ ลืมปิด-เปิดใหม่แล้วคิดว่าติดตั้งไม่สำเร็จ)

QAddress already in use / port ถูกใช้งานอยู่แล้ว
สาเหตุ

มี terminal เก่าที่รัน dotnet run/watch ค้างอยู่จากรอบก่อน ยังไม่ได้ปิด

วิธีแก้

หา terminal เก่าที่ยังรันค้างอยู่ กด Ctrl+C เพื่อหยุด หรือปิดหน้าต่าง terminal นั้นทิ้งไปเลย แล้วค่อยรันใหม่ในหน้าต่างเดียว

Qเปิด URL แล้วเจอ "Your connection is not private"
สาเหตุ

certificate สำหรับพัฒนา (development HTTPS certificate) ยังไม่ได้รับความเชื่อถือจากเครื่อง

วิธีแก้

ลองใช้ URL แบบ http (port 5000) แทน https (port 5001) ไปก่อนสำหรับการฝึก หรือรันคำสั่ง dotnet dev-certs https --trust เพื่อให้เครื่องเชื่อถือ certificate นี้

Error ตอนเขียน C# พื้นฐาน
Qerror CS1002: ; expected
สาเหตุ

ลืมใส่เครื่องหมาย ; ท้ายบรรทัดคำสั่ง เป็น error ที่พบบ่อยที่สุดของคนเริ่มเขียน C#

วิธีแก้

เช็คบรรทัดที่ error บอก (เลขบรรทัดมักตรงหรือใกล้เคียงจุดที่ลืมจริง) เติม ; ท้ายบรรทัดนั้น

Qerror CS0103: The name 'x' does not exist in the current context
สาเหตุ

ใช้ตัวแปรที่ยังไม่ได้ประกาศ หรือสะกดชื่อตัวแปรผิด (พิมพ์ใหญ่-เล็กไม่ตรงกันก็นับว่าคนละชื่อ เช่น Age กับ age คือคนละตัวแปรกันใน C#)

วิธีแก้

เช็คว่าประกาศตัวแปรนี้ไว้แล้วหรือยัง (มีบรรทัด int age = ... อยู่ก่อนบรรทัดที่ error ไหม) และเช็คตัวสะกดให้ตรงกันทุกตัวอักษรรวมถึงตัวพิมพ์ใหญ่-เล็ก

QUnhandled exception: System.FormatException ตอนใช้ int.Parse
สาเหตุ

พยายามแปลงข้อความที่ไม่ใช่ตัวเลขให้เป็น int เช่น int.Parse("abc") หรือข้อความมีช่องว่าง/ อักขระแปลกปนอยู่

วิธีแก้

ใช้ int.TryParse แทน ซึ่งไม่ throw error แต่คืนค่า true/false บอกว่าแปลงสำเร็จไหม:

if (int.TryParse(text, out int number))
{
    Console.WriteLine(number);
}
else
{
    Console.WriteLine("ไม่ใช่ตัวเลข");
}
Error ในหน้า Razor Pages
Q404 Not Found ทั้งที่สร้างไฟล์ .cshtml แล้ว
สาเหตุ

ลืมใส่ @page ไว้บรรทัดแรกสุดของไฟล์ หรือชื่อไฟล์/URL ที่พิมพ์ไม่ตรงกับชื่อไฟล์จริง (case-sensitive บางระบบปฏิบัติการ เช่น Linux)

วิธีแก้

เช็คว่าบรรทัดแรกสุดของไฟล์ .cshtml คือ @page เช็คว่าไฟล์อยู่ในโฟลเดอร์ Pages/ จริง และเช็ค URL ที่พิมพ์ตรงกับชื่อไฟล์ทุกตัวอักษร

QThe model item passed into the dictionary is null / ไม่พบ property ของ Model
สาเหตุ

ไฟล์ .cshtml ไม่มี @model XxxModel หรือชื่อ class ใน @model ไม่ตรงกับ PageModel จริง

วิธีแก้

เช็คว่ามีบรรทัด @model XxxModel อยู่ใกล้บนสุดของไฟล์ และชื่อ XxxModel ตรงกับชื่อ class ในไฟล์ .cshtml.cs เป๊ะ (รวมตัวพิมพ์ใหญ่-เล็ก)

Qกด submit ฟอร์มแล้วค่าที่กรอกไม่เข้ามาที่ [BindProperty]
สาเหตุ

ชื่อใน asp-for ไม่ตรงกับชื่อ property ที่มี [BindProperty] หรือ form ไม่มี method="post"

วิธีแก้

เช็คว่า <form method="post"> ครบ และ asp-for="NewProduct.Name" สะกดตรงกับ property จริงในไฟล์ .cshtml.cs (รวมถึงชื่อ object ครอบด้านหน้าอย่าง NewProduct ด้วย)

Error เกี่ยวกับฐานข้อมูล (EF Core)
QNo database provider has been configured / Unable to resolve DbContext
สาเหตุ

ลืมลงทะเบียน DbContext ใน Program.cs หรือลืม inject package provider (เช่น Sqlite, SqlServer)

วิธีแก้
builder.Services.AddDbContext<AppDbContext>(options =>
    options.UseSqlite("Data Source=app.db"));

ต้องมีบรรทัดนี้อยู่ก่อน builder.Build() เสมอ และต้องติดตั้ง package Microsoft.EntityFrameworkCore.Sqlite (หรือตัวที่ตรงกับ database ที่ใช้) ไว้ก่อน

Qดึงข้อมูลที่เชื่อมกัน (เช่น order.Customer) ได้ null ตลอด ทั้งที่มีข้อมูลจริง
สาเหตุ

ลืมเขียน .Include() ตอน query เป็น error ที่เจอบ่อยที่สุดในหัวข้อ relationship

วิธีแก้
var orders = await db.Orders
    .Include(o => o.Customer)   // ต้องมีบรรทัดนี้
    .ToListAsync();

EF Core ไม่ดึงข้อมูลที่เชื่อมกันมาให้อัตโนมัติ ต้องสั่งชัดเจนทุกครั้งที่ต้องการใช้ข้อมูลนั้น

QPending model changes / No migrations found ตอนรันโปรเจกต์
สาเหตุ

แก้ Model (เพิ่ม/ลบ field) แล้วแต่ยังไม่ได้สร้าง migration ใหม่ ทำให้โครงสร้างในโค้ดกับใน database จริงไม่ตรงกัน

วิธีแก้
dotnet ef migrations add ชื่อที่อธิบายการเปลี่ยนแปลง
dotnet ef database update

ต้องรันสองบรรทัดนี้ทุกครั้งหลังแก้โครงสร้าง Model (เพิ่ม field, เปลี่ยน type, เพิ่ม relationship ฯลฯ)

Error ใน Blazor
Qแก้ค่าตัวแปรแล้วหน้าจอไม่อัพเดทให้
สาเหตุ

แก้ค่าจากที่ที่ Blazor ไม่รู้ว่าต้องวาดใหม่ (เช่น callback จาก JavaScript, Timer, event ที่ไม่ใช่ของ Blazor เอง)

วิธีแก้
private void OnSomeExternalEvent()
{
    someValue = newValue;
    StateHasChanged();   // สั่งให้วาด UI ใหม่ด้วยตัวเอง
}
QObject reference not set to an instance of an object ใน component
สาเหตุ

พยายามแสดงข้อมูลก่อนที่ OnInitializedAsync จะโหลดข้อมูลเสร็จ (component render ครั้งแรกก่อนข้อมูลจะมาถึง)

วิธีแก้
@if (products is null)
{
    <p>กำลังโหลด...</p>
}
else
{
    @foreach (var p in products) { <p>@p.Name</p> }
}

เช็คว่าข้อมูล null หรือยังก่อนแสดงผลเสมอ โดยเฉพาะข้อมูลที่โหลดจากฐานข้อมูลแบบ async

Error ตอน Runtime ทั่วไป
QObject reference not set to an instance of an object (NullReferenceException)
สาเหตุ

พยายามเข้าถึง property ของตัวแปรที่เป็น null เช่น หาสินค้าด้วย id ที่ไม่มีอยู่จริง แล้วเอา ผลลัพธ์ (ซึ่งเป็น null) ไปใช้ต่อทันทีโดยไม่เช็คก่อน เป็น error ที่พบบ่อยที่สุดโดยรวม

วิธีแก้
var product = await db.Products.FindAsync(id);
if (product is null)
{
    return NotFound();
}
// ใช้ product ต่อได้อย่างปลอดภัยตรงนี้

เช็ค null ทุกครั้งหลัง query ข้อมูลที่อาจไม่เจอ ก่อนเอาไปใช้งานต่อเสมอ

Qโปรแกรมค้าง (deadlock) ตอนเรียก method แบบ async
สาเหตุ

เรียก async method แบบผิดวิธี เช่น ใช้ .Result หรือ .Wait() แทนที่จะใช้ await ทำให้ thread รอกันเองแบบวนไม่จบ

วิธีแก้
// ผิด — อาจทำให้ deadlock
var order = GetOrderAsync(id).Result;

// ถูก — ใช้ await เสมอ
var order = await GetOrderAsync(id);

กฎง่ายๆ: ถ้า method เป็น async ให้ใช้ await เรียกเสมอ อย่าใช้ .Result หรือ .Wait()

QCORS policy ไม่อนุญาต (ตอนมี frontend แยก เช่น React)
สาเหตุ

backend ยังไม่ได้เปิด CORS ให้ origin ของ frontend ที่กำลังเรียกเข้ามา

วิธีแก้
builder.Services.AddCors(options =>
{
    options.AddPolicy("AllowDev", policy =>
        policy.WithOrigins("http://localhost:5173")
              .AllowAnyHeader().AllowAnyMethod());
});
// ...
app.UseCors("AllowDev");
ถ้าลองแก้ตามนี้แล้วยังไม่หาย ลองคัดลอกข้อความ error ตัวเต็มไปค้นหาตรงๆ ระบุคำว่า "ASP.NET Core" ต่อท้ายด้วยเพื่อผลลัพธ์ที่ตรงประเด็นกว่า
