01

ภาพรวมระบบ

ระบบไม่ได้เป็นเพียง dashboard แสดงผลอย่างเดียว แต่เป็นเครื่องมือที่ สร้างและควบคุมแคมเปญโฆษณาจริงบน Facebook โดยเรียกใช้ Facebook Marketing API เบื้องหลัง ผู้ใช้ตั้งค่าทุกอย่าง — งบประมาณ กลุ่มเป้าหมาย ครีเอทีฟ — จากหน้าเว็บของเราเอง แล้วระบบจะส่งคำสั่งไปสร้าง/แก้ไข/หยุด campaign บน Facebook ให้อัตโนมัติ พร้อมดึงผลลัพธ์กลับมาแสดงผลแบบละเอียด

02

ฟีเจอร์หลัก

สร้าง & จัดการแคมเปญ

Write API

สร้างโครงสร้าง Campaign → Ad Set → Ad ได้ทั้งหมดจากในระบบ ไม่ต้องสลับไปหน้า Ads Manager

  • เลือกวัตถุประสงค์แคมเปญ (Traffic, Conversion, Engagement ฯลฯ)
  • อัปโหลดรูป/วิดีโอ และจัดการครีเอทีฟหลายชุด
  • เปิด/ปิด/พักแคมเปญได้จากปุ่มเดียว พร้อมยืนยันก่อนทำจริง
  • ทำสำเนา (duplicate) แคมเปญที่เคยได้ผลดี

งบประมาณแบบยืดหยุ่น

Budget Engine

ตั้งงบได้ละเอียดกว่ามาตรฐานของ Facebook เอง

  • รายวัน / lifetime — ใช้ค่ามาตรฐานจาก API โดยตรง
  • รายชั่วโมง / รายสัปดาห์ — ระบบคำนวณและปรับ daily budget อัตโนมัติผ่าน scheduler
  • ตั้งเพดานงบรวมต่อลูกค้า พร้อมแจ้งเตือนก่อนงบหมด
  • Pacing report เทียบงบที่ตั้งไว้กับงบที่ใช้จริง

เลือกกลุ่มเป้าหมาย

Targeting API

เข้าถึงกลุ่มลูกค้าที่ต้องการอย่างละเอียด

  • อายุ, เพศ, สถานะ
  • ตำแหน่งที่ตั้งระดับจังหวัด / อำเภอ / รัศมีรอบจุด
  • ความสนใจ, พฤติกรรม, Custom Audience และ Lookalike
  • บันทึกกลุ่มเป้าหมายเป็นเทมเพลตใช้ซ้ำได้

Dashboard วิเคราะห์ผล

Insights API

ข้อมูลตัวเลขละเอียดระดับมืออาชีพ อัปเดตใกล้เรียลไทม์

  • Reach, Impressions, CTR, CPC, CPM, Conversion, ROAS
  • Breakdown ตามอายุ / จังหวัด / placement / อุปกรณ์
  • เปรียบเทียบหลายแคมเปญ/หลายลูกค้าในกราฟเดียว
  • Export รายงานเป็น PDF / Excel ส่งลูกค้าได้ทันที

บริหารหลายลูกค้า

Multi-tenant

ออกแบบมาให้ agency ดูแลได้หลายบัญชีพร้อมกันโดยไม่ปนกัน

  • เชื่อม Business Manager / Ad Account ของลูกค้าแต่ละราย
  • สลับมุมมองระหว่างลูกค้าได้เร็ว
  • แบ่งสิทธิ์ทีมงาน (แอดมิน / มีเดียบายเออร์ / ดูอย่างเดียว)
  • Activity log บันทึกทุกการเปลี่ยนแปลงในแต่ละบัญชี

แจ้งเตือนอัจฉริยะ

Automation

ลดเวลาที่ต้องนั่งเฝ้าหน้าจอ

  • แจ้งเตือนเมื่อ CPC/CPM พุ่งผิดปกติ
  • แจ้งเตือนเมื่องบใกล้หมดหรือแคมเปญหยุดทำงาน
  • กติกาอัตโนมัติ เช่น หยุด ad set ที่ CPA เกินเพดานที่ตั้งไว้
  • สรุปผลประจำวัน/สัปดาห์ส่งเข้า LINE หรืออีเมล
03

โครงสร้างข้อมูล & การเชื่อมต่อ API

โครงสร้างโฟลเดอร์โปรเจ็ค (monorepo) และลำดับชั้นข้อมูลที่ระบบต้องรองรับ

โครงสร้างโฟลเดอร์ (Monorepo)
adloop/ ├─ apps/ │ ├─ web → Next.js frontend (Dashboard UI 5 หน้า) │ └─ api → Backend service (REST API) ├─ packages/ │ ├─ ads-provider → AdsProvider interface + MockAdsProvider + FacebookAdsProvider │ └─ ui → shared UI components (shadcn/ui-based) ├─ .ai/ │ ├─ plan.md → แผนงานรวมทุกเฟส │ ├─ phase-0..6-*.md → รายละเอียด + prompt ต่อเฟส │ └─ reference/ │ ├─ spec.html │ ├─ dashboard-mockup.html │ └─ ui-guidelines.md ├─ AGENTS.md ├─ CLAUDE.md └─ .gitignore
ลำดับชั้นข้อมูล (Database Hierarchy)
Agency (1 บริษัท) └─ Client / Business Manager (ลูกค้าแต่ละราย) └─ Ad Account (บัญชีโฆษณา) └─ Facebook Page (เพจที่ใช้ยิง) └─ Campaign → Ad Set → Ad
→

เส้นทางการเรียก API: ระบบของเรา (Backend) ↔ Facebook Graph API / Marketing API ↔ Facebook Business Manager ของลูกค้า โดยต้องขอสิทธิ์ผ่าน OAuth และ System User Token สำหรับแต่ละ Business Manager ที่เชื่อมเข้ามา

04

ขั้นตอนขอสิทธิ์จาก Meta

เพราะระบบต้อง สร้างและแก้ไขโฆษณาแทนผู้ใช้ จึงต้องขอ permission ระดับสูงจาก Meta ก่อนใช้กับลูกค้าจริงได้

ขั้นตอนรายละเอียดสิ่งที่ต้องเตรียม
1. สร้าง Meta App ลงทะเบียนแอปประเภท Business ใน Meta for Developers บัญชี Business Manager, โดเมนเว็บไซต์
2. ขอ Permission ขอสิทธิ์ ads_management, business_management, pages_read_engagement Privacy Policy, คำอธิบาย use case ชัดเจน
3. App Review ส่งวิดีโอสาธิตการใช้งานฟีเจอร์จริงให้ Meta ตรวจสอบ ระบบต้องพัฒนาเสร็จในระดับ demo ก่อน
4. Business Verification ยืนยันตัวตนธุรกิจ (เอกสารบริษัท) เพื่อปลดล็อกการใช้งานระดับ production เอกสารจดทะเบียนบริษัท
5. Go live เชื่อมต่อ Business Manager ของลูกค้าแต่ละรายผ่าน OAuth ได้จริง —
⚠

ข้อควรระวัง: ก่อนผ่าน App Review ระบบใช้ได้เฉพาะกับ ad account ของนักพัฒนาเอง (สูงสุด 5 บัญชีทดสอบ) ควรวางแผนขั้นตอนนี้ตั้งแต่ต้น เพราะใช้เวลาตรวจสอบหลายสัปดาห์และอาจถูกตีกลับให้แก้ไข
