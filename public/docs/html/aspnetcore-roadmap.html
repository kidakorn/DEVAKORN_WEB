ASP.NET Core — Zero to Hero Roadmap

รวมทุกไฟล์ที่ทำไว้ให้เป็นเส้นทางเดียว เปิดไฟล์ตามลำดับที่ 1-4 (แกนหลัก) และเปิดฝั่งขวา (เครื่องมือเสริม) ประกอบเมื่อจำเป็น ไม่ต้องเปิดพร้อมกันทั้งหมด

1
aspnetcore-setup-to-run.html
เตรียมเครื่องมือ + รันเว็บแอปแรกให้สำเร็จ
เช็ค .NET SDK, ติดตั้ง C# Dev Kit, สร้างโปรเจกต์, รันจริง, เห็นผลใน browser ยังไม่มีการเขียนโค้ดเนื้อหา
เริ่มที่นี่~20-30 นาที
2
aspnetcore-beginner-plan.html
พื้นฐานโปรแกรมมิ่งจนถึง Web App เต็มรูปแบบ (19 หัวข้อ)
เริ่มจาก "โปรแกรมคืออะไร" ไม่อิงพื้นฐานเดิม ไล่ผ่าน C# พื้นฐาน (ตัวแปร, if/else, loop, method, class, List) จนถึงสร้าง Razor Pages + Blazor + EF Core CRUD ครบ มีโจทย์พร้อมเฉลยที่ซ่อนไว้ทุกหัวข้อ
แกนหลัก6-8 สัปดาห์19 หัวข้อ
3
aspnetcore-webapp-deepdive.html
ยกระดับสู่เว็บแอปใช้งานจริง (8 module)
ต่อยอดจากไฟล์ที่ 2 — Layout กลาง, Validation เต็มรูปแบบ, ข้อมูลเชื่อมหลาย table, ระบบ Login, Blazor แบบจัดการ state ข้าม component, error handling, เตรียม deploy มีเฉลยซ่อนไว้ทุก module เช่นกัน
แกนหลัก4-5 สัปดาห์8 module
ทำหลังจบไฟล์ที่ 2 แล้วเท่านั้น เพราะอ้างอิงโค้ดจากพื้นฐานที่วางไว้ก่อน
4
โปรเจกต์ฝึกของตัวเอง
ลงมือทำโปรเจกต์จริงที่ไม่มีเฉลย
เลือกระบบเล็กๆ ที่อยากทำ (เช่น ระบบจัดการสต๊อกสินค้าง่ายๆ) แล้วสร้างเองทั้งหมดโดยไม่เปิดไฟล์ 2-3 ดู ใช้ cheat sheet และ FAQ ช่วยเมื่อติดขัดแทน นี่คือจุดที่วัดว่าเนื้อหาที่เรียนมาแปลงเป็นทักษะจริงแค่ไหน
บทพิสูจน์2-3 สัปดาห์

เครื่องมือเสริม (เปิดคู่กันระหว่างเรียน ไม่ต้องอ่านเรียงลำดับ)

ไม่ใช่ส่วนหนึ่งของเส้นทางหลัก แต่ควรเปิดค้างไว้ข้างๆ ระหว่างลงมือเขียนโค้ดจริง

aspnetcore-cheatsheet.html สรุป syntax หน้าเดียว เปิดดูเร็วตอนลืมว่าเขียนยังไง
aspnetcore-faq-errors.html เจอ error แดงๆ เปิดไฟล์นี้ก่อนค้นหาที่อื่น
