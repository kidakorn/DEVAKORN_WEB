รอคิว1.1 — ย้าย token + เช็ค signature 
งานของ session นี้คือ PLAN.md Phase 1 ข้อ 1-2 เท่านั้น:

อ่าน CLAUDE.md, PLAN.md, DESIGN.md ก่อนเริ่ม โดยเฉพาะ Decision Log
ข้อ 2-3 ใน DESIGN.md

1. ย้าย LINE Channel Access Token จาก backend/apps-script/Code.gs
   ไปเก็บใน Script Properties ของ Apps Script (ใช้
   PropertiesService.getScriptProperties()) แก้ replyMessage() ให้
   อ่าน token จากตรงนั้นแทนค่าที่ฝังไว้

   Properties เช่นกัน) เทียบกับ header ที่ LINE ส่งมา ถ้าไม่ตรงให้
   ปฏิเสธ request ทันที ไม่ประมวลผลต่อ

รอคิว2.3 — แก้ Code.gs ให้เขียนลง Firebase
