แผนติดตั้ง Flutter

เช็คลิสต์ 10 ข้อสำหรับติดตั้งเครื่องมือ Flutter ให้พร้อมทำ Phase 2 ข้อ 3 — กดติ๊กเก็บความคืบหน้าไว้ระหว่างเปิดหน้านี้ (รีเฟรชหรือปิดแท็บแล้วค่าจะรีเซ็ต ให้จำจากที่ทำไปแล้วเอง หรือดูสถานะจริงจาก PLAN.md) รายละเอียดขั้นตอนเต็ม ๆ อยู่ในไฟล์ smart_farm_iot_tool_setup.html

ทำตามลำดับบนลงล่าง แต่ละข้อล็อกกันอยู่บ้าง (เช่น Git ต้องมีก่อน Flutter ถึงติดตั้งผ่าน)

ดูขั้นตอนละเอียด
  1. ไปที่ git-scm.com/download/win ดาวน์โหลดตัวติดตั้งเวอร์ชันล่าสุด (เลือกให้อัตโนมัติตาม Windows 64-bit)
  2. รันตัวติดตั้ง กด Next ไปเรื่อย ๆ ด้วยค่า default ได้เลย เช็คให้แน่ใจว่า "Git from the command line and also from 3rd-party software" ถูกเลือกไว้
  3. ติดตั้งเสร็จแล้ว ปิด terminal ที่เปิดค้างอยู่ทั้งหมด แล้วเปิดใหม่ (ค่า PATH จะยังไม่อัปเดตถ้าไม่เปิด terminal ใหม่)
ดูขั้นตอนละเอียด
เปิด terminal (PowerShell หรือ Command Prompt ก็ได้) พิมพ์ 2 บรรทัดนี้ (แทนชื่อ/อีเมลเป็นของพี่เอง) ค่านี้จะโชว์ในทุก commit ที่ทำต่อไป 
git config --global user.name "ชื่อพี่"
git config --global user.email "อีเมลพี่"
ดูขั้นตอนละเอียด
เปิด terminal ใหม่ พิมพ์: 
git --version
ถ้าขึ้นเลขเวอร์ชัน (เช่น git version 2.4x.x) แปลว่าใช้ได้แล้ว ถ้าขึ้น "not recognized" ให้ปิด terminal ทุกหน้าต่างแล้วเปิดใหม่อีกรอบ (บางทีต้อง restart เครื่องด้วยถ้ายังไม่หาย)
ดูขั้นตอนละเอียด
  1. เปิด VS Code กด Ctrl+Shift+X เปิด Extensions panel
  2. ค้นหา Flutter เลือกตัวที่พัฒนาโดย Dart Code (ลิงก์โดยตรง: marketplace.visualstudio.com — Dart-Code.flutter)
  3. กด Install — ตัว Dart extension จะติดตั้งตามมาให้อัตโนมัติ ไม่ต้องหาลงเอง
ดูขั้นตอนละเอียด
  1. กด Ctrl+Shift+P เปิด Command Palette พิมพ์ Flutter: New Project แล้วกด Enter
  2. ถ้ายังไม่เคยมี Flutter SDK ในเครื่อง VS Code จะเสนอปุ่ม "Download SDK" ให้กด — มันจะดาวน์โหลดและตั้งค่า PATH ให้อัตโนมัติ (ไม่ต้องโหลด .zip เองแล้วไปตั้ง PATH มือแบบวิธีทางการที่ docs.flutter.dev/get-started/install/windows เขียนไว้ — วิธีผ่าน VS Code นี้ง่ายกว่าสำหรับคนเพิ่งเริ่ม)
  3. รอจนดาวน์โหลดเสร็จ (ใช้เวลาสักพัก ไฟล์ค่อนข้างใหญ่) แล้วเลือกตำแหน่งโฟลเดอร์สำหรับสร้างโปรเจ็คทดสอบ (ยังไม่ต้องสร้างจริงก็ได้ กด Escape ออกได้หลัง SDK โหลดเสร็จ)
ดูขั้นตอนละเอียด
  1. ไปที่ developer.android.com/studio ดาวน์โหลดตัวติดตั้งสำหรับ Windows
  2. รันตัวติดตั้ง เลือก "Standard" installation type (ค่า default) จะติดตั้ง Android SDK, Android SDK Platform-Tools, Android Virtual Device ให้ครบในขั้นตอนเดียว
  3. เปิด Android Studio ครั้งแรก ไปที่ Settings → Plugins ค้นหา Flutter กด Install (ถ้าถามให้ติดตั้ง Dart ด้วย กด Yes)
ดูขั้นตอนละเอียด
  1. เปิด Android Studio ไปที่ Device Manager (ไอคอนมือถือด้านขวา หรือ More Actions → Virtual Device Manager)
  2. กด Create Device เลือกรุ่นมือถือกลาง ๆ (เช่น Pixel 6 หรือ Pixel 7) กด Next
  3. เลือก System Image (เวอร์ชัน Android) — ถ้ายังไม่เคยโหลด จะมีปุ่ม Download ข้าง ๆ ให้กดโหลดก่อน แนะนำเลือกเวอร์ชันล่าสุดที่มีให้
  4. กด Finish รอสักครู่ emulator จะโชว์ในรายการ กดปุ่ม ▶ เพื่อเปิดทดสอบว่าจำลองมือถือขึ้นมาได้จริง
ดูขั้นตอนละเอียด
เปิด terminal ใหม่ (สำคัญ ต้องเปิดใหม่หลังติดตั้งของก่อนหน้าเสร็จ) พิมพ์: 
flutter doctor -v
ถ้าเห็นบรรทัด "Android licenses not accepted" ให้รัน: 
flutter doctor --android-licenses
แล้วพิมพ์ y ยอมรับไปเรื่อย ๆ จนครบทุกข้อ รันคำสั่งแรกอีกครั้งเพื่อดูว่าติ๊กเขียวครบหรือยัง (อ้างอิงขั้นตอนตามเอกสารทางการที่ docs.flutter.dev/get-started/install/windows)
ดูขั้นตอนละเอียด
จำเป็นสำหรับให้ Flutter สร้าง symlink ตอน build โปรเจ็คที่มี plugin (เกือบทุกโปรเจ็คจริงมี) ไม่เปิดจะเจอ error "Building with plugins requires symlink support" ทีหลัง 
start ms-settings:developers
พิมพ์คำสั่งนี้ใน terminal จะเปิดหน้า Settings ให้เลย หรือเข้าเองที่ Settings → Privacy & Security → For developers เปิดสวิตช์ Developer Mode เป็น ON แล้วรีสตาร์ทเครื่อง (แนะนำให้รีสตาร์ทให้ชัวร์)
ดูขั้นตอนละเอียด
เปิด emulator ที่สร้างไว้ในข้อ 7 ให้รันอยู่ก่อน (หรือต่อมือถือจริงผ่าน USB debugging) แล้วเปิด terminal ไปที่โฟลเดอร์ไหนก็ได้ที่ไม่ใช่ repo หลัก พิมพ์: 
flutter create test_app
cd test_app
flutter run
ถ้ามีมากกว่า 1 target ให้มันถามว่าจะรันบนไหน เลือก emulator/มือถือที่เตรียมไว้ รอสักครู่จะเห็นแอปตัวอย่าง (มีปุ่ม + กดแล้วเลขนับเพิ่ม) ขึ้นบนหน้าจอจริง — ถ้าขึ้นแปลว่าเครื่องพร้อม 100% แล้ว กด q ใน terminal เพื่อหยุด แล้วลบโฟลเดอร์ test_app ทิ้งได้เลย
ถ้าติดขัดตรงไหน: ส่ง error message หรือผลจาก flutter doctor -v มาได้เลย ช่วยดูให้ทีละจุด
