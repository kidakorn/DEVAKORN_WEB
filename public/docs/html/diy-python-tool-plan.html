AS400 / IBMi · LANSA · RPG

แผนสร้าง Tool อัตโนมัติด้วยตัวเอง

Python tool ที่ทำ export + FTP + git commit + tag ให้อัตโนมัติ รองรับหลายชุดโปรแกรมผ่าน manifest file — ทดสอบทุกอย่างบน pub400.com (IBMi สาธารณะฟรี) ก่อน ค่อยย้ายไปใช้กับเครื่องบริษัทจริง
สถานะ: รอการอนุมัติแผน ก่อนเริ่ม Phase 1

เป้าหมาย

ยกระดับ Path A (ที่ทำมือตอนนี้) ให้เป็นอัตโนมัติ โดยรองรับหลายชุดโปรแกรม (เช่น BMPCD99R เป็นชุดหนึ่ง โปรแกรมอื่นเป็นอีกชุด) ผ่านไฟล์ manifest แทนการเขียนโค้ดใหม่ทุกครั้งที่มีชุดโปรแกรมเพิ่ม

แนวคิดสำคัญ: RCMD ผ่าน FTP

แทนที่จะรัน CPYTOSTMF ผ่านหน้าจอ 5250 เอง ให้ Python สั่งคำสั่งนี้ทางไกลผ่านกลไก RCMD ที่ FTP server ของ IBMi รองรับอยู่แล้ว (ฟีเจอร์มาตรฐาน ไม่ใช่ hack) ทำให้ export และดึงไฟล์ลง PC เกิดในคำสั่งเดียวจบ

ความเสี่ยงที่ต้องเช็คก่อน: บางองค์กรปิดสิทธิ์ RCMD ด้วยเหตุผลความปลอดภัย อนุญาตแค่ GET/PUT ไฟล์เท่านั้น — Phase 1 จึงเป็นการทดสอบเรื่องนี้ก่อนลงทุนสร้างส่วนที่เหลือ ถ้าใช้ไม่ได้จะสลับไปใช้ CL program บน IBMi ทำ export แทน แล้วให้ Python ทำแค่ FTP GET + git ต่อ

ไฟล์ที่จะสร้าง

ไฟล์หน้าที่
groups.jsonmanifest กำหนดว่าแต่ละชุดโปรแกรมมี member อะไรบ้าง อยู่ library ไหน
ibmi_git_sync.pyสคริปต์หลัก: export ผ่าน RCMD, FTP GET, git add/commit
requirements.txtรายการ Python package (ตั้งใจใช้ standard library เป็นหลัก ไม่ต้องติดตั้งอะไรเพิ่ม)
README.mdวิธีใช้งานและวิธีเพิ่มชุดโปรแกรมใหม่

Phase การทำงาน

00

ตั้ง Sandbox บน pub400.com

สมัคร account ฟรีที่ pub400.com (รัน IBM i 7.5 จริง ได้ library ส่วนตัว 2 ตัว พื้นที่ 300MB) สร้าง library และ member จำลอง (เช่น TESTPGM, TESTPGMD, TESTPGMC) แทนของจริงของบริษัท เพื่อทดสอบทุกอย่างได้โดยไม่ต้องขอสิทธิ์ใคร

เผื่อเวลา: password TN5250 กับ FTP/SSH อาจไม่ตรงกัน ต้องแก้ auth ก่อน
# 1. สมัคร account เปิด https://pub400.com/ → กด "Signup now" → กรอกฟอร์ม → รอ email ยืนยัน # 2. Login ทดสอบผ่าน TN5250 (ACS หรือ IBM i Access) Server: pub400.com Port: 23 (5250) หรือ SSH port 2222 # 3. สร้าง library ทดสอบ (พิมพ์ในหน้าจอ 5250) CRTLIB LIB(GITTEST) TEXT('sandbox for git pipeline test') # 4. สร้าง source file และ member ทดสอบ CRTSRCPF FILE(GITTEST/QRPGLESRC) TEXT('test source') # แล้วใช้ STRSEU หรือ WRKMBRPDM สร้าง member ชื่อ TESTPGM ใส่โค้ดสั้นๆ
01

ทดสอบสิทธิ์ RCMD (บน pub400 ก่อน)

สคริปต์เล็กทดสอบว่า FTP profile บน pub400 สั่ง RCMD CPYTOSTMF ได้จริงไหม กับ member ทดสอบตัวเดียว — ถ้าผ่านบน pub400 แสดงว่าแนวทางนี้ใช้ได้ในทางเทคนิคแน่นอน ก่อนเอาไปเช็คสิทธิ์กับเครื่องบริษัทอีกที

ต้องผ่านก่อนไป Phase 2
# ทดสอบผ่าน command line FTP บน PC (ยังไม่ต้องใช้ Python) ftp pub400.com Name: <your pub400 user> Password: <your pub400 password> ftp> quote rcmd CPYTOSTMF FROMMBR('/QSYS.LIB/GITTEST.LIB/QRPGLESRC.FILE/TESTPGM.MBR') TOSTMF('/home/<youruser>/TESTPGM.rpgle') STMFOPT(*REPLACE) 250 Command ran successfully. ← ถ้าเห็นแบบนี้ แปลว่า RCMD ใช้ได้ ftp> quit
02

Export + Download อัตโนมัติ (บน pub400)

อ่าน groups.json วนลูป export ทุก member ในกลุ่มทดสอบ ผ่าน RCMD แล้ว FTP GET ลง local folder ตามโครงสร้างที่วางไว้

# โครงร่างฟังก์ชัน (skeleton เท่านั้น — ยังไม่ implement logic จนกว่าจะอนุมัติ Phase นี้) def load_groups(path: str) -> dict: ... def export_member_via_rcmd(ftp, library, file, member, dest_ifs) -> None: ... def download_via_ftp(ftp, remote_path, local_path) -> None: ... def sync_group(group_name: str, group_def: dict) -> list[str]: ...
03

Git Integration

git add + git commit อัตโนมัติ ใส่ชื่อกลุ่มและรายชื่อ member ใน commit message

# สิ่งที่ Python จะสั่งให้ subprocess รันแทน (ตัวอย่าง prompt) git add . git commit -m "sync GITTEST_SET: TESTPGM, TESTPGMD, TESTPGMC (2026-08-24)"
04

Tagging Workflow

เพิ่ม flag หรือ prompt ให้สร้าง annotated tag ตาม naming convention release-<วันที่>-<ชื่อกลุ่ม>-TAI พร้อมกัน

# เมื่อรันด้วย flag --promote python ibmi_git_sync.py --group GITTEST_SET --promote # ภายในจะสั่ง git tag -a release-2026-08-24-GITTEST_SET-TAI -m "promote GITTEST_SET to TAI"
05

ย้ายไปทดสอบกับสภาพแวดล้อมจริงของบริษัท

เมื่อทุก phase ผ่านบน pub400 ครบแล้ว ค่อยเปลี่ยนค่า connection ใน config ให้ชี้ไปที่เครื่องบริษัทแทน แล้วทดสอบกับ library DEV จริงเป็นขั้นสุดท้ายก่อนใช้งานจริง

จุดนี้ต้องเช็คสิทธิ์ RCMD กับเครื่องบริษัทอีกรอบ อาจได้ผลต่างจาก pub400
# แก้แค่ config ไม่แก้โค้ด { "host": "your-company-ibmi.internal", "user": "<your real user>" }
06

เอกสารและวิธีเพิ่มชุดใหม่

เขียน README อธิบายวิธีเพิ่มชุดโปรแกรมใหม่ใน groups.json โดยไม่ต้องแก้โค้ด

ตัวอย่างโครงสร้าง groups.json (แนวคิด ยังไม่ใช่โค้ดจริง)

{
  "BMPCD99R_SET": {
    "library": "DEV",
    "members": [
      {"name": "BMPCD99R",  "file": "QRPGLESRC"},
      {"name": "BMPCD99RD", "file": "QDDSSRC"},
      {"name": "BMPCD99C",  "file": "QCLSRC"}
    ]
  }
}

เช็คลิสต์ก่อนเริ่ม Phase 0

  • สมัคร account ที่ pub400.com แล้ว (รอ email ยืนยันสักครู่หลังสมัคร)
  • ทดลอง login ผ่าน TN5250 ได้แล้ว และเช็คว่า FTP/SSH login ด้วย password เดียวกันได้หรือไม่
  • มี Python ติดตั้งบนเครื่อง PC (เวอร์ชัน 3.8 ขึ้นไป)
  • มี git ติดตั้งบนเครื่องเดียวกัน
  • รู้ FTP host / user ที่ใช้ promote บนเครื่องบริษัทจริง (ใช้ตอน Phase 5 เท่านั้น ยังไม่ต้องใช้ตอนนี้)
แผนนี้รอการอนุมัติ — ยังไม่มีการเขียนโค้ดใดๆ จนกว่าจะตอบตกลง
