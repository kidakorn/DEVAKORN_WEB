04

ทำตามลำดับนี้ จะไม่งง

  1. สร้างโฟลเดอร์เปล่าตามผังในข้อ 05 ก่อน (ยังไม่ต้องใส่ไฟล์)
  2. ลากไฟล์ MOVE เข้าไปก่อน — แค่ย้าย+เปลี่ยนนามสกุลจาก .ino เป็น .cpp เนื้อหาข้างในเหมือนเดิมทุกตัวอักษร ยังไม่ต้องแก้อะไร
  3. ทำไฟล์ MERGE — เปิด 2 ไฟล์เดิม copy เนื้อหาทั้งคู่มาแปะรวมในไฟล์ใหม่ไฟล์เดียว (ยังไม่ต้องแก้ logic แค่รวมไฟล์)
  4. เขียนไฟล์ .h คู่กันทุกไฟล์ — ใส่แค่บรรทัดประกาศฟังก์ชัน (ดูตัวอย่างในข้อ 01)
  5. สร้างไฟล์ NEW ทั้งหมดในข้อ 03 — เริ่มจาก secrets.h กับ platformio.ini ก่อน เพราะจำเป็นต่อการ build
  6. วาง CLAUDE.md, PLAN.md, DESIGN.md ที่ root (มีให้แล้ว ไม่ต้องเขียนใหม่)
  7. ลองสั่ง pio run ดูว่า build ผ่านไหม — ถ้า error ส่วนใหญ่จะเป็นเพราะ .h ประกาศฟังก์ชันไม่ครบ แก้ตรงนั้นไปทีละจุด
